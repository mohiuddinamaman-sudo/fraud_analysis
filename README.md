SQL analysis for A.1, A.2 and fraudster identification.

## A.1

GAIA transaction view showing customer ID,
customer country and transaction amount.

## A.2

first transaction was a completed card payment
over $10 USD equivalent.

## Fraud Analysis

list who show unusual transaction behaviour.
